ALDUIN X — ULTIMATE EDITION
Запуск: через локальный HTTP-сервер. Service Worker не работает корректно через file://.

Возможности:
Dashboard, дневник, галерея IndexedDB, полноэкранный viewer, лор, календарь, хронология, профиль, настройки, экспорт/импорт, частицы, live FPS monitor, PWA и Service Worker.
FPS не ограничивается искусственно: requestAnimationFrame работает по частоте обновления дисплея/браузера.
