ALDUIN ULTIMATE
================
Пароль по умолчанию: ALDUIN2026

Что внутри:
- index.html — полностью новый интерфейс
- style.css — premium dark fantasy UI
- app.js — вся логика в одном файле
- IndexedDB для изображений (намного надёжнее localStorage для больших фото)
- дневник с архивом и автосохранением черновика
- полноэкранная галерея + стрелки + клавиши ← →
- профиль с сохранением изображения
- экспорт/импорт JSON
- музыка
- PWA + Service Worker
- адаптивная desktop/mobile навигация
- адаптивные частицы
- requestAnimationFrame без искусственного FPS-лимита

ВАЖНО ПРО 120 FPS:
Сайт не может "заставить" экран работать на 120/144 Гц. requestAnimationFrame синхронизируется с реальной частотой дисплея/браузера. Если телефон и браузер дают 120 Гц — интерфейс и анимации смогут идти в этом ритме. Никакого setInterval(60) или искусственного cap 60 FPS для анимаций здесь нет.

ПАРОЛЬ:
Измени const PASSWORD в app.js.
На статическом сайте пароль не является настоящей серверной защитой, потому что JavaScript доступен пользователю.
