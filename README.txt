ALDUIN X — LIVE2D + MULTI-AI EDITION

Это исходный ALDUIN X с добавленной отдельной вкладкой «Live2D». Остальные разделы сайта сохранены: главная, дневник, галерея, AI, лор, календарь, хронология, профиль и настройки.

LIVE2D:
- Поддержка Cubism 3/4 через .model3.json.
- Загрузка ZIP модели или целой папки модели.
- Автоматическая распаковка ZIP в браузере.
- Автоматическое преобразование ссылок на .moc3, текстуры, motions, expressions, physics и другие файлы.
- Масштаб, центрирование и сброс модели.
- Следование взгляда за курсором.
- Ручные эмоции и тестовые движения.
- AI → Live2D: Gemini, Groq, OpenAI, DeepSeek, Grok, OpenRouter и остальные провайдеры ALDUIN могут управлять эмоцией/движением.
- Есть скрытая команда [[LIVE2D emotion=happy motion=auto]]. Если AI её не вернул, ALDUIN использует простой автоматический анализ текста как запасной вариант.

ТРЕБОВАНИЯ:
- Запускай через локальный HTTP-сервер, а не через file://.
- Для Live2D Runtime и JSZip нужен интернет при первой загрузке страницы, потому что библиотеки подключаются через CDN.
- Для Cubism 3/4 используется Cubism Core; сам Live2D Core не включён в ZIP из-за лицензии Live2D.
- Модель пользователя не включена в архив: загрузи свою .zip модель или папку с .model3.json.

AI:
- Gemini выбран по умолчанию.
- Groq, OpenAI, DeepSeek, Grok/xAI, OpenRouter, Mistral, Together AI и Custom OpenAI-compatible сохранены.
- API-ключи хранятся в localStorage браузера устройства.

ВАЖНО:
Live2D-модель должна содержать все необходимые файлы. Если ZIP содержит несколько моделей, выбери ZIP с нужным .model3.json. Для лицензированных моделей используй их согласно условиям автора/Live2D.
