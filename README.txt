ALDUIN — COMPACT LIVE2D BUILD

1. Распакуй ZIP.
2. Загрузи папку на GitHub Pages / любой обычный HTTP(S)-хостинг.
3. Открой index.html через сайт (не file://, если браузер блокирует CDN).
4. Открой вкладку Live2D.
5. Нажми «🐉 Встроенная модель» — модель Miara уже лежит внутри архива.
6. Для своей модели можно использовать «ZIP модели» или «Папка модели».

В архиве оставлены только необходимые runtime-файлы встроенной модели:
- model3.json
- .moc3
- .cdi3.json
- .physics3.json
- texture_00.png
- 3 motion3.json
